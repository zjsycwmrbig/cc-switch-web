# CC Switch Uint

> チーム全員のプロバイダーを、ひとつのモデルのように使う。

CC Switch Uint はチーム向けのマルチユーザー AI プロバイダー／モデル集約プラットフォームです。散在する API キー、公式サブスクリプション、自前の中継を、認可・計量・ルーティング可能な共有能力に変えます。

## ビジョン

- **プロバイダーはチームのもの**：各自が登録し、チームが必要に応じて使う。
- **権限を正確に委譲**：クォータ、モデル範囲、期限、リクエスト数、Token を所有者が決める。
- **クライアントは1つの入口だけ**：残高と権限のあるプロバイダーを自動選択。

## 主な機能

- マルチユーザー：アカウント、API キー、個人クォータ、同時実行・レート制限。
- プロバイダーマーケット：公開/非公開、申請と承認、ユーザー別利用ランキング、残高照会。
- クォータと共有：既定/共有予算、自動承認、共有コード。
- モデルとルーティング：カタログ管理、1:1 マッピング、順序変更可能な自動ルーティング。
- 公式アカウントセンター：Codex / Copilot / Grok のログイン・紐付け・ローテーション。
- 利用状況とコスト：リクエストログ、ユーザー/プロバイダー/モデル別統計、価格とクォータ進捗。

## アーキテクチャ

- バックエンド：Rust（axum）+ SQLite、Web 8890 / ゲートウェイ 15721。
- フロントエンド：React + Vite、静的ファイルはディスク配信で UI 変更時に Rust 再ビルド不要。
- 同期：Codex 設定と集約カタログを生成、固定バックアップと restore に対応。
