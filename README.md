# CC Switch Uint

> 让团队像使用一个模型一样，使用所有人的供应商。

CC Switch Uint 是一个面向团队的多用户 AI 供应商与模型聚合平台。它把分散在每个人手里的 API Key、官方订阅和自建中转，汇聚成一份可授权、可计量、可路由的共享能力。

## 愿景

- **供应商属于团队，而不是某台机器**：每个人上传自己的供应商，团队按需使用。
- **能力可以被精确授权**：额度、模型范围、截止时间、请求次数与 Token 都由拥有者决定。
- **客户端只需要一个入口**：自动选择有余额、有权限且可用的供应商。

## 核心能力

- 多用户工作空间：账号、API Key、个人额度、并发与速率限制。
- 供应商库：公开/私有发布，申请审批，用户用量排行与余额查询。
- 额度与共享：默认额度、共享预算、免审规则、分享口令。
- 模型与路由：目录管理、单对单映射、多供应商自动路由（可拖动排序）。
- 官方账号授权中心：Codex / Copilot / Grok 统一登录、绑定与轮询。
- 用量与成本：请求日志、按用户/供应商/模型统计、模型定价与配额进度。

## 架构

- 后端：Rust（axum）+ SQLite；Web 控制台 8890，共享代理网关 15721。
- 前端：React + Vite；生产静态资源由磁盘托管，UI 改动无需重编 Rust。
- 同步：生成 Codex 配置与聚合模型目录，支持固定备份与 restore 还原。
